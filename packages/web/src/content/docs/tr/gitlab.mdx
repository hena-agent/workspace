hena-agent, GitLab CI/CD işlem hattınız veya GitLab Duo aracılığıyla GitLab iş akışınızla bütünleşir.

Her iki durumda da hena-agent, GitLab çalıştırıcılarınızda çalışacaktır.

---

## GitLab CI

hena-agent normal bir GitLab işlem hattında çalışır. Bunu bir [CI component](https://docs.gitlab.com/ee/ci/components/) olarak bir işlem hattına oluşturabilirsiniz.

Burada hena-agent için topluluk tarafından oluşturulan bir CI/CD bileşeni kullanıyoruz — [nagyv/gitlab-opencode](https://gitlab.com/nagyv/gitlab-opencode).

---

### Özellikler

- **İş başına özel işlemleri kullanın**: hena-agent parçalarının kullanıma veya devre dışı bırakmak için hena-agent'u özel bir yapılandırma dizini ile yapılandırın; örneğin `./config/#custom-directory`.
- **Minimum kurulum**: CI bileşeni hena-agent'u arka planda kurar; yalnızca hena-agent yapılandırmasını ve ilk istemi oluşturmanız gerekir.
- **Esnek**: CI bileşeni, davranışını özelleştirmek için çeşitli girişleri destekler

---

### Kurulum

1. hena-agent kimlik doğrulamanızı JSON **Ayarlar** > **CI/CD** > **Değişkenler** altında Dosya türü CI ortam değişkenleri olarak saklayın. Bunları "Maskeli ve gizli" olarak işaretlediğinizden emin olun.
2. Aşağıdakileri `.gitlab-ci.yml` dosyanıza ekleyin.

   ```yaml title=".gitlab-ci.yml"
   include:
     - component: $CI_SERVER_FQDN/nagyv/gitlab-opencode/opencode@2
       inputs:
         config_dir: ${CI_PROJECT_DIR}/hena-agent-config
         auth_json: $HENA_AGENT_AUTH_JSON # The variable name for your Hena Agent authentication JSON
         command: optional-custom-command
         message: "Your prompt here"
   ```

Daha fazla girdi ve bu bileşene yönelik kullanım durumları için [check out the docs](https://gitlab.com/explore/catalog/nagyv/gitlab-opencode).

## GitLab Duo

hena-agent, GitLab iş akışınızla bütünleşir.
Bir yorumda `@hena-agent`'dan bahsedin; hena-agent, GitLab CI işlem hattınızdaki görevleri yürütecektir.

---

### Özellikler

- **Sorunları önceliklendirin**: hena-agent'dan bir sorunu araştırıp size açıklamasını isteyin.
- **Düzelt ve uygula**: hena-agent'dan bir sorunu düzeltmesini veya bir özelliği uygulamasını isteyin.
  Yeni bir dal oluşturacak ve değişikliklerle birlikte bir birleştirme isteği oluşturacaktır.
- **Güvenli**: hena-agent, GitLab çalıştırıcılarınızda çalışır.

---

### Yapılandırma

hena-agent, GitLab CI/CD işlem hattınızda çalışır; bunu ayarlamak için ihtiyacınız olacaklar:

:::tip
Güncel talimatlar için [**GitLab docs**](https://docs.gitlab.com/user/duo_agent_platform/agent_assistant/)'a göz atın.
:::

1.  GitLab ortamınızı yapılandırın
2.  CI/CD'yi kurma
3.  Bir AI model sağlayıcısı API anahtarını gösterir
4.  Hizmet hesabı oluşturun
5.  CI/CD değişkenlerini yapılandırma
6.  Bir akış yapılandırma dosyası oluşturun; işte bir örnek:

        <details>

    <summary>Akış yapılandırması</summary>

    ```yaml
    image: node:22-slim
    commands:
      - echo "Installing hena-agent"
      - npm install --global hena-agent
      - echo "Installing glab"
      - export GITLAB_TOKEN=$GITLAB_TOKEN_HENA_AGENT
      - apt-get update --quiet && apt-get install --yes curl wget gpg git && rm --recursive --force /var/lib/apt/lists/*
      - curl --silent --show-error --location "https://raw.githubusercontent.com/upciti/wakemeops/main/assets/install_repository" | bash
      - apt-get install --yes glab
      - echo "Configuring glab"
      - echo $GITLAB_HOST
      - echo "Creating Hena Agent auth configuration"
      - mkdir --parents ~/.local/share/hena-agent
      - |
        cat > ~/.local/share/hena-agent/auth.json << EOF
        {
          "anthropic": {
            "type": "api",
            "key": "$ANTHROPIC_API_KEY"
          }
        }
        EOF
      - echo "Configuring git"
      - git config --global user.email "hena-agent@gitlab.com"
      - git config --global user.name "Hena Agent"
      - echo "Testing glab"
      - glab issue list
      - echo "Running Hena Agent"
      - |
        hena-agent run "
        You are an AI assistant helping with GitLab operations.

        Context: $AI_FLOW_CONTEXT
        Task: $AI_FLOW_INPUT
        Event: $AI_FLOW_EVENT

        Please execute the requested task using the available GitLab tools.
        Be thorough in your analysis and provide clear explanations.

        <important>
        Please use the glab CLI to access data from GitLab. The glab CLI has already been authenticated. You can run the corresponding commands.

        If you are asked to summarize an MR or issue or asked to provide more information then please post back a note to the MR/Issue so that the user can see it.
        You don't need to commit or push up changes, those will be done automatically based on the file changes you make.
        </important>
        "
      - git checkout --branch $CI_WORKLOAD_REF origin/$CI_WORKLOAD_REF
      - echo "Checking for git changes and pushing if any exist"
      - |
        if ! git diff --quiet || ! git diff --cached --quiet || [ --not --zero "$(git ls-files --others --exclude-standard)" ]; then
          echo "Git changes detected, adding and pushing..."
          git add .
          if git diff --cached --quiet; then
            echo "No staged changes to commit"
          else
            echo "Committing changes to branch: $CI_WORKLOAD_REF"
            git commit --message "Codex changes"
            echo "Pushing changes up to $CI_WORKLOAD_REF"
            git push https://gitlab-ci-token:$GITLAB_TOKEN@$GITLAB_HOST/gl-demo-ultimate-dev-ai-epic-17570/test-java-project.git $CI_WORKLOAD_REF
            echo "Changes successfully pushed"
          fi
        else
          echo "No git changes detected, skipping push"
        fi
    variables:
      - ANTHROPIC_API_KEY
      - GITLAB_TOKEN_HENA_AGENT
      - GITLAB_HOST
    ```

        </details>

Ayrıntılı talimatlar için [GitLab CLI agents docs](https://docs.gitlab.com/user/duo_agent_platform/agent_assistant/)'a başvurabilirsiniz.

### Örnekler

GitLab'da hena-agent'u nasıl kullanabileceğinize dair bazı örnekleri burada bulabilirsiniz.

:::tip
`@hena-agent`'dan farklı bir tetikleyici ifade kullanacak şekilde yapılandırabilirsiniz.
:::

- **Bir sorunu açıklama**

  Bu yorumu bir GitLab sayısına ekleyin.

  ```
  @hena-agent explain this issue
  ```

  hena-agent konuyu okuyacak ve net bir açıklama ile yanıt verecektir.

- **Bir sorunu düzeltme**

  In a GitLab issue, say:

  ```
  @hena-agent fix this
  ```

  hena-agent yeni bir dal oluşturacak, değişiklikleri uygulayacak ve değişiklikleri içeren bir birleştirme isteği açacaktır.

- **Birleştirme isteklerini inceleme**

  GitLab birleştirme isteğine aşağıdaki yorumu bırakın.

  ```
  @hena-agent review this merge request
  ```

  hena-agent, birleştirme isteğini inceleyecek ve geri bildirim sağlayacaktır.
